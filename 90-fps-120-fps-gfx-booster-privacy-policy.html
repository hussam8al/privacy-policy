Information Collection & Local Storage (Data Safety)

Google Play Data Safety Section Disclosure

The Application does not require user registration and operates no proprietary backend servers to collect user data:

  • No Sensitive Personal Information Collected: We do not request, access, or collect your name, email address, phone number, precise GPS location, contacts, photos, microphone, or camera.
  • Strictly On-Device Storage: Language and theme preferences, custom GFX profiles, automatic backups of Active.sav and UserCustom.ini, and Reflex Trainer scores are stored exclusively inside your device's private application storage (Room SQLite and Jetpack DataStore) and never leave your device.
  • Android Auto-Backup Rules: System cloud/device transfer rules (data_extraction_rules.xml) include only your local Room profile database while excluding temporary backup files.

أداة تركيز شبكة اللعبة وبنق الاتصال (بدون VPN)

قفل Wi-Fi منخفض الكمون • قياس البنق الحي • تحكم Shizuku الاختياري بالنظام
ShizukuNetFocusService • WifiLock (WIFI_MODE_FULL_LOW_LATENCY)

تعمل ميزة "تركيز شبكة اللعبة والبنق" (Game Network & Ping Focus) محلياً بالكامل بطلب يدوي منك، وقد تم إزالة خدمة VpnService نهائياً من التطبيق:

  • لا يستخدم التطبيق VPN مطلقاً: لا يطلب التطبيق إذن BIND_VPN_SERVICE، ولا ينشئ أي نفق VPN، ولا يغيّر إعدادات DNS، ولا يعترض أو يوجّه حركة مرور الإنترنت عبر أي خوادم خارجية.
  • وضع Wi-Fi منخفض الكمون وقياس البنق: يفعّل التطبيق قفل WIFI_MODE_FULL_LOW_LATENCY الرسمي في أندرويد لتقليل تذبذب الواي فاي ويقيس زمن استجابة الشبكة (Ping) محلياً أثناء اللعب.
  • التحكم الاختياري عبر Shizuku وتنظيف الخلفية: عند ربط تطبيق Shizuku يدوياً من قِبل المستخدم، يطبّق سياسات الشبكة القياسية للنظام (cmd netpolicy) لتقليل استهلاك تطبيقات الخلفية فقط؛ وفي الوضع القياسي يكتفي بتقليل عمليات الخلفية غير المستثناة دون فحص أو تسجيل أي حزم بيانات.

Game Network & Live Ping Focus (No VPN)

Wi-Fi Low-Latency Lock • Live Ping Telemetry • Optional Shizuku OS NetPolicy
ShizukuNetFocusService • WifiLock (WIFI_MODE_FULL_LOW_LATENCY)

The optional "Game Network & Ping Focus" feature operates strictly on-device when started by you, with zero use of Android's VpnService:

  • No VPN & No Traffic Interception: The Application does not declare BIND_VPN_SERVICE, creates no VPN tunnel, configures no custom DNS, and never intercepts, inspects, or routes traffic through external servers.
  • Wi-Fi Low-Latency Lock & Live Ping: Acquires Android's official WIFI_MODE_FULL_LOW_LATENCY Wi-Fi lock and monitors real-time network latency (ping) directly on your device.
  • Optional Shizuku OS Policy & Background Cleanup: When the user explicitly connects Shizuku, the app applies standard Android cmd netpolicy rules to limit background contention; in Standard Mode it pauses non-excluded background processes without reading or logging any network packets.

الأذونات والخدمات الأمامية المعلنة في التطبيق

شرح تفصيلي لجميع الأذونات في AndroidManifest.xml
  • SYSTEM_ALERT_WINDOW
    العرض فوق التطبيقات الأخرى: يُستخدم حصرياً عندما يفعّل المستخدم يدوياً "المؤشر التكتيكي العائم" (CrosshairOverlayService) أو "شريط التحكم السريع بالدقة" (QuickControlOverlayService). لا يلتقط التطبيق محتوى الشاشة ولا يسجل النقرات.
  • POST_NOTIFICATIONS
    إشعارات الحالة السريعة: تُستخدم فقط لعرض إشعار حالة للأدوات التي يشغلها المستخدم بنفسه (المؤشر العائم، شريط الدقة، تركيز الشبكة المحلية، أو قفل استجابة الجيروسكوب) مع زر إيقاف فوري (Stop).
  • WRITE_SETTINGS • WRITE_SECURE_SETTINGS
    تعديل إعدادات العرض والنظام: يُستخدم فقط عند تفعيل المستخدم لخيار تثبيت تردد الشاشة (peak_refresh_rate / min_refresh_rate)، أو سرعة استجابة اللمس، أو أقصى سطوع، مع حفظ القيم الأصلية تلقائياً لاستعادتها بضغطة زر.
  • HIGH_SAMPLING_RATE_SENSORS
    مستشعر الجيروسكوب عالي التردد (>200Hz): يُستخدم محلياً فقط لقراءة حركة الجيروسكوب داخل "مدرّب رد الفعل والتصويب" وخدمة "تثبيت أقصى استجابة للجيروسكوب" (GyroResponsivenessService). تُعالج القراءات لحظياً في الذاكرة ولا يتم حفظها أو إرسالها.
  • KILL_BACKGROUND_PROCESSES • WAKE_LOCK
    تحرير الذاكرة الخلفية: يُستخدم فقط عند ضغط المستخدم على زر التعزيز في "معزّز الألعاب" لتحرير ذاكرة RAM من العمليات الخلفية غير المستثناة.
  • WRITE_EXTERNAL_STORAGE (maxSdkVersion="28")
    تصدير ملفات الإعدادات على أندرويد 7–9 فقط: يُستخدم فقط على الإصدارات القديمة (API 24–28) لحفظ نسخة من ملف الإعدادات المصدّر في مجلد التنزيلات.
  • INTERNET • ACCESS_NETWORK_STATE • ACCESS_WIFI_STATE
    الاتصال بالشبكة: يُستخدم لقياس زمن الاستجابة (Ping) محلياً، ولتحميل إعلانات Google AdMob والتحقق من المشتريات والتحديثات عبر Google Play.

Permissions & Foreground Services Disclosure

Complete breakdown of all AndroidManifest.xml declarations
  • SYSTEM_ALERT_WINDOW
    Display Over Other Apps: Used strictly when the user manually activates the floating Crosshair Reticle (CrosshairOverlayService) or Floating Aspect Slider Pill (QuickControlOverlayService). It never reads screen content or captures user inputs.
  • POST_NOTIFICATIONS
    Active Tool Status Notifications: Used solely to display a persistent status notification for user-started tools (Crosshair Overlay, Quick Aspect Pill, Local Network Focus, or High-Rate Gyroscope Lock) providing an instant "Stop" action.
  • WRITE_SETTINGS • WRITE_SECURE_SETTINGS
    System Display & Touch Settings: Used strictly upon explicit user command to toggle max brightness, pointer speed, or display refresh rate pinning (peak_refresh_rate / min_refresh_rate), with automatic backup and one-tap restore.
  • HIGH_SAMPLING_RATE_SENSORS
    High-Rate Gyroscope Sensor (>200Hz): Used purely on-device for the Reflex & Aim Trainer and user-started Gyroscope Responsiveness lock (GyroResponsivenessService). Sensor data is processed in RAM and never stored or transmitted.
  • KILL_BACKGROUND_PROCESSES • WAKE_LOCK
    Background Memory Optimization: Used only when the user taps Boost in Game Booster to free background RAM from non-excluded background processes.
  • WRITE_EXTERNAL_STORAGE (maxSdkVersion="28")
    Legacy Export Fallback (Android 7–9 only): Used solely on API 24–28 when exporting configuration backups to the Downloads directory.
  • INTERNET • ACCESS_NETWORK_STATE • ACCESS_WIFI_STATE
    Network Access: Used to measure connection ping/jitter locally, serve Google AdMob ads, and verify Google Play Billing purchases and mandatory app updates.
